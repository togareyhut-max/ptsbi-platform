=== PTSBI Members ===
Stable tag: 1.0.3

Modul anggota terpisah — reusable di banyak website.

== Kompatibilitas Premium Organization ==

| Versi premium | PTSBI Members |
|---------------|---------------|
| 2.7.x (modul anggota masih di dalam premium) | Tidak dipasang bersamaan. Aktivasi tidak error, tetapi plugin ini tidak memuat class duplikat — gunakan premium saja ATAU upgrade premium. |
| 3.0.3+ (tanpa class-members.php di folder premium) | Pasangkan keduanya — ini skenario yang disarankan. |

== Instalasi ptsbi.org ==

1. Upload ptsbi-premium 3.0.3 (pastikan TIDAK ada includes/class-members.php di folder premium).
2. Aktifkan Premium Organization.
3. Upload ptsbi-members 1.0.3.
4. Aktifkan PTSBI Members.

Hapus folder duplikat: ptsbi-premium262, salinan lama production yang masih embed modul anggota.
