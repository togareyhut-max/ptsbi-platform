== Description ==

KontenKit Core v2 menambahkan pengalaman artikel premium, CPT Portfolio & Testimonial, SEO dasar, dan banyak shortcode layout.

== Features ==

* Dashboard admin bertab (Umum, Artikel, CPT, SEO, Shortcode)
* Brand colors, custom CSS, maintenance mode
* Post meta: subtitle, label badge, YouTube embed
* TOC otomatis, reading time, post views, meta bar
* Social share + sticky sidebar, author box premium, related grid
* Newsletter call-to-action box
* Open Graph + Schema.org Article
* CPT: kk_portfolio, kk_testimonial
* Shortcodes: button, alert, columns, icon_box, accordion, quote, youtube, pricing, testimonials, portfolio, cta, spacer, divider

== Installation ==

1. Upload kontenkit-core.zip via Plugins → Add New → Upload
2. Activate
3. Open KontenKit menu and save settings
4. Flush permalinks if CPT archives 404
